QC LIMIT - dự án iPhone (SwiftUI)
1. Tạo repo GitHub, đẩy toàn bộ thư mục này lên nhánh main (nhớ cả thư mục .github).
2. Vào tab Actions > "Build IPA" > chờ chạy xong (khoảng 3-6 phút).
3. Tải artifact "QCLimit-ipa" > giải nén ra QCLimit.ipa.
4. Mở Sideloadly, kéo QCLimit.ipa vào, đăng nhập Apple ID, Start.
5. iPhone: Cài đặt > Cài đặt chung > VPN & Quản lý thiết bị > tin cậy Apple ID. Bật Chế độ nhà phát triển nếu iOS yêu cầu.
6. Mở app, chạm micro, cho phép micro + nhận diện giọng nói, đọc "1914 cộng trừ 20".
